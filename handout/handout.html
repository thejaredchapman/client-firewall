Client Firewall

Keep one client's information out of another client's work in Claude.

If you work inside several companies at once, one rushed paste into Claude can put Client B's numbers into Client A's deliverable.

Set up in 3 steps

  1. In claude.ai, create one Project per client.
  2. Paste the instructions below into the Project's instructions.
  3. Fill in the rules file for that client and add it to the Project's knowledge.

Before Claude writes a word

● GREENNothing risky. Claude drafts as normal.

● AMBERSensitive details the task doesn't need. Claude offers a cleaned-up version first.

● REDAnother client's details or a never-share item. Claude stops and tells you what to remove.
